# AI Academy - AI学社

> 面向大学生的 AI 学习平台前端站点

## 项目简介

AI学社是一个系统化的人工智能学习平台，为大学生提供从入门到进阶的 AI 课程。

## 技术栈

- **构建工具**: Vite
- **前端**: 原生 JavaScript/TypeScript
- **后端**: Supabase
- **监控**: Sentry
- **测试**: Vitest
- **部署**: GitHub Pages

## 本地开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```
